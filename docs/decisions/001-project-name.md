# 001 : nom de travail Foylo

Date : 17 septembre 2026. Statut : Décidé.

## Contexte et décision

Le nom doit évoquer le foyer et pouvoir couvrir la coordination familiale au-delà du pointage des enfants. Foylo est retenu comme nom de travail. L'orthographe du dossier a été explicitement corrigée en Foylo.

## Conséquences

Le projet local est situé dans `~/dev/Foylo`. La disponibilité commerciale et les domaines restent à vérifier séparément. Foilo est une ancienne orthographe corrigée, pas un nom alternatif.
