# 002 : socle technique

Date : 17 septembre 2026. Statut : Décidé.

## Contexte et décision

La synthèse finale retient Expo / React Native avec TypeScript, PostgreSQL et Drizzle. Le domaine est relationnel et le partage de la logique métier TypeScript est recherché.

## Alternatives et conséquences

Une application iPhone entièrement native a été discutée pour faciliter une future Watch. Le choix retenu privilégie le partage du domaine et la possibilité d'Android ultérieurement.

Cette décision ne sélectionne ni fournisseur d'authentification, ni hébergeur, ni framework d'API, ni outil de synchronisation. Elle ne déclenche pas la création du code.
